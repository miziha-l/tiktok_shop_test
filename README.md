# TikTok Shop Concept

A polished, responsive commerce experience built with Next.js App Router.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

Import the repository in Vercel and set **Root Directory** to `tiktok_page` (or import this folder directly). The framework preset, install command, and build command are detected automatically.

No environment variables are required for the current demo product data. Product images are served through the Next.js image optimizer from Unsplash.
